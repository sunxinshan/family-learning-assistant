### 2.3 统一异常

- `AppError` 业务错误基类。
- 参数校验错误统一处理。
- 404、401、403 统一错误码。
- 未处理异常统一 500，不向客户端返回堆栈。
- 错误响应包含 `request_id`。

错误结构：

```json
{
  "error": {
    "code": "business_rule_failed",
    "message": "业务规则未满足",
    "details": null,
    "request_id": "..."
  }
}
```

### 2.4 请求 ID 与日志

- 支持传入合法 `X-Request-ID`，否则生成 UUID。
- 响应返回 `X-Request-ID`。
- JSON 日志包含请求 ID、方法、路径、状态码、耗时。
- 开发环境支持 console 日志。
- 敏感字段不应进入日志，后续模块继续执行脱敏规范。

### 2.5 数据库与迁移

- SQLAlchemy 2.x Base 和 Session 工厂。
- SQLite 开发数据库。
- MySQL + PyMySQL 配置入口。
- Session 统一 commit/rollback/close。
- 自动创建 SQLite 文件目录。
- Alembic 初始空迁移 `0001_initial`。
- 未创建任何正式业务表。
