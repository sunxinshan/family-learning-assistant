# 家庭学习助手前端原型开发实施记录

**阶段：** Phase 0 - 前端交互原型  
**完成日期：** 2026-11-02  
**技术栈：** React 19 + TypeScript + Vite + React Router  
**数据方案：** Mock API + LocalStorage

---

## 1. 交付概览

本次交付实现了一个可运行的 Web 原型，覆盖总体架构文档中确认的用户、Agent、任务、词库、词汇练习、听写练习、学习记录和管理员边界。

原型不是静态页面集合，已实现以下真实可操作闭环：

- Agent 先预览、后确认的任务创建。
- Agent 展示任务修改前后差异并确认更新。
- Agent 两阶段确认删除任务，并连带删除练习记录。
- Excel / CSV 文件上传、模拟解析和确认导入词库。
- 词汇练习答题、反馈、保存退出、刷新恢复、完成结果。
- 听写练习播放、输入、反馈、进度保存和结果展示。
- 公共词库浏览、复制及个人副本独立维护。
- 学习记录和错题从练习事实计算。
- 管理员管理公共词库、查看用户学习概况和操作日志。

本阶段不包含正式后端、真实 LLM、LangGraph、SSE 服务或数据库。

## 3. 页面结构与导航

### 3.1 主应用导航

- 学习助手 `/`
- 学习任务 `/tasks`
- 词库 `/vocabulary`
- 学习记录 `/learning`
- 管理后台 `/admin`（仅管理员）

账户菜单提供退出登录和重置演示数据。移动端导航转为抽屉。

### 3.2 独立页面

| 页面 | 路由 | 主要作用 |
|---|---|---|
| 登录/注册 | `/login` | 演示身份选择、注册与数据重置 |
| 任务详情 | `/tasks/:taskId` | 任务配置、快照、练习记录、编辑与两阶段删除 |
| 词库详情 | `/vocabulary/:libraryId` | 搜索、添加、编辑、批量修改词性、批量删除、公共词库复制 |
| 词汇练习 | `/practice/vocabulary/:taskId` | 四选一词汇理解、反馈、恢复与结果 |
| 听写练习 | `/practice/dictation/:taskId` | Web Speech 播放、拼写输入、反馈与结果 |

练习页面不复用主应用侧边栏，采用聚焦式全屏布局，避免答题时被业务导航打断。

## 5. Mock API 说明

所有页面和 Mock Agent 均通过 `src/api/mockApi.ts` 访问业务能力。后续接入 FastAPI 时优先替换这一层实现。

### 5.1 Auth API

- `login(nickname, password)`
- `register(nickname, password)`
- `current()`
- `logout()`

### 5.2 Conversation API

- `get(userId)`
- `save(userId, messages)`
- `clear(userId)`

### 5.3 Task API

- `list(userId)`
- `get(taskId, userId)`
- `create(userId, draft)`
- `update(userId, taskId, changes)`
- `remove(userId, taskId)`

规则：

- 任务只属于创建它的用户。
- 创建任务保存独立内容快照。
- 固定任务创建后不允许修改学习内容和数量。
- 删除任务同时删除练习 Attempt 和答题记录。
- 任务状态只使用 `in_progress` / `completed`。

### 5.4 Vocabulary API

- `listMine(userId)`
- `listPublic(userId)`
- `get(libraryId, userId)`
- `create(userId, draft)`
- `copy(userId, libraryId)`
- `insertEntries(...)`
- `updateEntry(...)`
- `removeEntries(...)`
- `createPublic(userId, draft)`
- `togglePublish(userId, libraryId)`
- `removePublic(userId, libraryId)`

公共词库复制时重新生成词条 ID，形成完整个人副本。

### 5.5 Practice API

- `startOrResume(taskId, userId)`
- `getActive(taskId, userId)`
- `get(attemptId)`
- `submitAnswer(taskId, userId, answer)`
- `saveExit(attemptId)`

每次练习创建独立 Attempt。未完成 Attempt 会恢复；答题事实按题保存；完成时根据正确内容重新计算任务进度。

### 5.6 Learning API

- `getStats(userId)`
- `listAttempts(userId)`

统计从 Practice 答题事实重新计算，包括练习次数、平均正确率、掌握数、待复习错题、分项正确率和最近 7 天活动。

### 5.7 Admin API

- `listUsers(adminId)`
- `resetPassword(adminId, userId)`
- `listLogs(adminId)`
- `getUserStats(adminId, userId)`

管理员只能读取用户学习结果，不提供修改任务、答题结果或掌握状态的接口。

### 5.8 Action API

- `isExecuted(actionId)`
- `execute(action, userId)`

确认动作由 action_id 去重。只有确认后才会进入 Service 写操作，执行成功后记录 action_id。

## 6. Mock Agent

### 6.1 支持场景

1. 普通问答与引导。
2. 创建个人词库。
3. 上传 `.xlsx` / `.csv` 并导入词库。
4. 创建词汇或听写任务。
5. 修改长期任务配置。
6. 两阶段删除任务。
7. 查询学习记录与错题摘要。

### 6.2 事件协议

`src/types/domain.ts` 定义与目标 SSE 协议同构的事件：

```ts
type AgentEvent =
  | { type: 'message'; data: { content: string } }
  | { type: 'progress'; data: { stage: string; message: string } }
  | { type: 'tool_status'; data: ToolExecution }
  | { type: 'confirmation_required'; data: PendingAction }
  | { type: 'error'; data: { code: string; message: string } }
  | { type: 'done'; data: { executionId: string } }
```

`mockAgent.ts` 顺序发出事件，聊天页面按事件驱动状态更新，不依赖轮询或固定延时推断业务状态。

### 6.3 确认机制

- 所有创建、修改、导入操作先返回 `confirmation_required`。
- 操作预览包含目标、配置、影响、修改差异和确认/取消。
- 删除任务先生成第一次删除预览。
- 第一次确认只执行校验并生成新的 stage 2 action。
- 第二次确认后才调用删除 Service。
- 取消不写入业务数据。
- 已处理 action 在消息流中标记为“已处理”并禁用按钮。

### 6.4 执行详情

Tool 执行卡片默认折叠，展开后展示：

- Tool 名称。
- 参数。
- 执行状态。
- 耗时。
- 结果。
- 错误信息。
- 敏感字段脱敏说明。

## 10. 已知问题与原型边界

1. Excel/CSV 解析为固定模拟数据，不读取真实文件内容。
2. 登录密码以演示字段存入 LocalStorage，不具备真实安全性。
3. 会话使用单一长期 Conversation，不支持多会话管理。
4. Agent 通过关键词与预设场景模拟，不包含真实自然语言理解。
5. 不接入真实 SSE，仅使用同构事件协议模拟事件流。
6. 听写音频依赖浏览器 Web Speech API；不支持该 API 的浏览器会给出提示。
7. 批量编辑当前支持统一修改词性，未扩展为多字段批量编辑。
8. 连续正确阈值、自动复习间隔算法在总体设计中尚未最终确定，本原型未固化具体算法。
9. 管理员用户管理当前包含查看概况和重置密码，未实现账户停用与删除。
10. 公共词库复制后独立维护已实现，但未实现版本差异提示或自动更新。
11. 任务内容快照已固定，尚未实现正式后端的事务一致性、幂等持久化和审计存储。

## 11. 后续接入 FastAPI、SSE 和 LangGraph 的调整点

### 11.1 API 层

- 保持页面调用签名不变时，优先替换 `mockApi.ts` 实现为 HTTP Client。
- 把 LocalStorage 初始化逻辑替换为后端查询和缓存。
- 统一处理认证过期、权限错误和结构化业务错误。

### 11.2 Agent / SSE

- 将 `mockAgent` 的事件输出替换为真实 SSE `EventSource` / `fetch` 流。
- 保持 `message`、`progress`、`tool_status`、`confirmation_required`、`error`、`done` 事件协议。
- 增加 event_id、conversation_id、timestamp 和断线重连游标。
- 确认请求提交 action_id 与服务端配置 Hash。
- 前端只展示服务端运行状态，不自行推断 Graph 状态。

### 11.3 Task / Practice / Learning

- 页面和 Agent 继续调用同一 Service。
- Task 创建必须由后端验证内容快照。
- Practice 恢复和进度更新应由后端事务保证。
- 学习统计从答题事实重新计算。
- 管理员接口保持只读学习结果边界。

### 11.4 权限

- 用户身份只能来自后端认证上下文。
- 前端 Mock 角色切换仅用于原型，不作为正式权限依据。
- Service 需要再次校验资源归属、角色和业务状态。
- 管理员 Tool 与普通用户 Tool 根据权限过滤。

### 11.5 运行与可观测性

- 接入 LangSmith 或等价追踪。
- 将 Tool 参数与结果脱敏后再组装执行详情。
- 为确认、删除、导入和任务修改增加正式业务操作日志。
- 服务端实现幂等持久化，不能只依赖前端按钮禁用。
