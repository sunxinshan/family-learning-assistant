## 5. 已完成功能

### 5.1 用户与权限

- 注册、登录、Access Token、Refresh Token 轮换。
- Refresh Token 可撤销；退出登录、停用账户会阻止继续访问。
- 普通用户和管理员权限隔离。
- 管理员不能代替普通用户修改业务数据。
- 管理员可看用户列表、停用/启用、重置密码、只读学习统计和操作日志。

### 5.2 词库

- 个人词库、公共词库、英语/语文配置。
- 名称、学科、描述、自定义标签、词条全部可编辑。
- 公共词库复制、发布、撤回、删除。
- 管理员可将自己创建的个人词库设为公共词库。
- 任务使用创建时快照，后续修改词库不影响已有任务。

### 5.3 Excel/CSV 导入

- 仅支持 `.xlsx` / `.csv`，服务端解析。
- 英语模板与语文模板分科：
  - 英语：单词、音标、词性、词义、例句、例句翻译。
  - 语文：词语、拼音、词性、释义、例句、例句翻译。
- 上传请求必须携带页面学科：
  `POST /materials/{id}/extractions?subject=chinese`
- 列名规则优先匹配；无法识别时调用 LLM 分析表头和最多 5 行样例。
- 服务端校验模型映射的索引范围、重复列和必填 `word`。
- 字段自动补充：
  - 英文缺音标：补 IPA。
  - 英文缺中文释义：补中文含义。
  - 中文词语缺拼音：补带声调拼音。
  - 仅填空字段，不覆盖用户已填写内容。
- 预览阶段支持逐条编辑、增删词条。
- Agent 导入预览的每个临时词条都有稳定唯一 ID，删除单个词条不会误删全部。

### 5.4 任务

- V1 正式仅开放听写任务。
- 新建任务默认固定任务。
- 默认不勾选任何词条；全选显示为 `1-N`，不使用字面量 `all`。
- 支持序号表达式：`2-10`、`4,8`；选择词库后自动带出正确学科。
- Agent 支持“前 10 个单词”“所有单词”等选择。
- 固定任务默认锁定词条快照，但任务名称、模式、分组、重做规则和听写配置可编辑。
- 任务创建后返回“打开任务”站内链接。
- 未产生 Attempt 显示“开始学习”，已产生显示“继续学习”。

### 5.5 听写配置与练习

- 线上听写自动判分。
- 线下听写由用户勾选错误项，保存 `evaluation_source=self_report`。
- 手动/自动播放、播放间隔、朗读次数。
- 听写页面显示当前分组进度：第 X/Y 组、组内第 M/N 个。
- 英语朗读内容：英语单词或中文含义。
- 语文语音直接朗读汉字词语本身，不使用拼音串拼读；页面同时展示拼音和中文含义作为提示。
- Attempt 中断恢复；重复提交不会重复累计。
- 固定任务进度按覆盖的唯一词条数；长期任务按掌握词条数。
- Learning 统计从答题事实重算。

### 5.6 Agent 与 SSE

- 意图：创建/修改/两阶段删除任务、创建/导入词库、学习查询、普通对话。
- 确认协议：`action_id + draft_version + config_hash`。
- 草稿编辑后递增版本，旧版本确认失败。
- Agent 写操作全部经过业务 Service。
- Agent Graph 在后台线程执行，SSE 断开不会直接取消 Graph。
- `agent_run_events` 持久化事件，支持 `after_sequence` 重放。
- 应用重启后 Pending Action 可恢复。
- 执行详情支持用户本人和管理员查看，敏感字段脱敏。

### 5.7 前端

- 默认使用 HTTP API；Mock 只在 `VITE_API_MODE=mock` 时启用。
- 登录状态、401 Refresh、Refresh 失败清理和跳转登录。
- 导航顺序：学习助手、词库、学习任务、学习记录、管理后台。
- Chat SSE、确认卡、草稿编辑、取消和任务/词库链接已接入真实后端。
- 练习页与对话分离。
- 桌面和移动端基础响应式布局。

## 6. 核心业务规则（不得无意破坏）

1. 前端页面不直接访问 Repository/LocalStorage 业务数据。
2. Service 是权限校验、业务规则和事务入口。
3. 跨模块访问使用 Service，不直接调用其他模块 Repository。
4. Agent 不直接访问业务数据库。
5. Conversation/Message 与 LangGraph Checkpoint 分离。
6. 听写任务使用独立内容快照。
7. 固定任务默认锁定词条快照；配置和模式可编辑，但不得静默替换快照。
8. V1 前端学习类型只读为“听写”。
9. 全选表达式使用 `1-N`，不显示 `all`。
10. 新任务默认固定，默认不选词条。
11. 词库学科必须由用户选择或明确解析参数决定，不能硬编码英语。
12. 公共词库只有管理员可发布；管理员只能公开自己创建的个人词库。
13. 线下自查完整计入统计和掌握，但保留 `self_report` 来源。
14. 已确认的 Agent 操作必须保持版本和 hash 校验。
15. 所有改动在测试通过后提交 Git。

## 12. 已知限制和风险

1. **Docker 镜像未实际运行**：本机没有可用 Docker daemon；Dockerfile、Compose、Nginx 配置已提供。
2. **LangSmith 未外部联调**：没有外部 LangSmith Key；核心 LLM 已接入 DeepSeek。
3. **LLM 凭据管理**：真实 DeepSeek Key 只保存在 `backend/.env` 和根目录 `.env`，两者均被 Git 忽略。
4. **MySQL Checkpoint 排序规则**：必须使用 `utf8mb4_0900_*`。
5. **浏览器语音合成**：依赖本机 Web Speech 和系统语音包；不可用时页面会提示。
6. **多实例 Agent 扩展**：当前 Agent Graph 在单进程后台线程中串行执行；水平扩展前应引入共享任务队列/专用 Worker。
7. **前端 Token 存储**：当前使用浏览器 LocalStorage；已有安全响应头、401 清理和 React 默认转义，但更严格方案可改 HttpOnly Cookie。
