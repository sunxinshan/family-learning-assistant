# 家庭学习助手前端原型设计方案

**版本：** V1.0  
**阶段：** Phase 0 - 前端交互原型  
**设计原则：** Agent 对话为核心入口，业务页面承接具体学习操作

---

## 1. 设计目标

本原型用于验证家庭学习助手的产品结构、核心交互和视觉方向，而不是静态界面演示。原型需要让用户在浏览器中完成以下闭环：

1. 通过 Agent 描述需求，获得结构化操作预览并确认执行。
2. 在不进入聊天输入框的情况下，于独立练习页面完成词汇或听写练习。
3. 在任务、词库和学习记录页面查看并管理学习数据。
4. 以管理员身份管理公共词库和用户，同时保持“管理员不代替用户学习”的边界。
5. 刷新页面后，对话、任务、词库和练习进度仍可恢复。

前端不实现正式后端，也不接入真实 LLM、LangGraph、SSE 服务或数据库。所有能力通过统一的 Mock API 与 Mock Agent 提供，接口边界为后续 FastAPI 接入预留替换空间。

## 2. 产品信息架构

### 2.1 导航结构

左侧导航保持简洁，按用户主要心智分为四组：

| 导航项 | 解决的问题 | 路由 |
|---|---|---|
| 学习助手 | 用自然语言发起业务操作、查询信息和继续待确认流程 | `/` |
| 学习任务 | 查看任务状态、进度，进入详情或继续学习 | `/tasks` |
| 词库 | 管理个人词库、浏览公共词库 | `/vocabulary` |
| 学习记录 | 查看练习、正确率、错题和掌握情况 | `/learning` |
| 管理后台 | 管理员管理用户、公共词库和操作日志 | `/admin` |

辅助入口：

- 左下角账户入口：查看当前身份，切换普通用户/管理员演示账号，退出登录。
- 移动端顶栏：菜单按钮、页面标题、账户入口。
- “重置演示数据”：仅在账户菜单或登录页的开发工具区域展示，避免误触。

### 2.2 导航原则

- Agent 是默认首页，也是业务操作的统一入口。
- 业务页面不重复实现 Agent 中的业务规则；页面操作与 Agent 操作调用同一套 Mock Service。
- 练习入口不在聊天窗口中直接展开答题，而是跳转到独立练习页面。
- 管理后台不会出现“代替用户修改任务、答案或掌握状态”的按钮。

## 3. 角色与权限设计

### 3.1 普通用户

- 只能访问自己的任务、词库、对话和练习记录。
- 可创建、编辑个人词库和词条。
- 可浏览并复制公共词库；复制后得到独立个人副本。
- 可通过 Agent 或任务详情修改/删除自己的任务。
- 可通过 Agent 查询自己的学习记录。

### 3.2 管理员

- 拥有普通用户能力。
- 可查看用户列表、用户学习概况和公共词库。
- 可创建、编辑、发布公共词库。
- 可查看关键操作日志。
- 原型中管理员权限标记清晰，但不提供修改用户答题结果、掌握状态或代替用户执行任务的入口。

### 3.3 原型账号

- 普通用户：`Alice`
- 管理员：`Admin` / `Manager`
- 登录页提供普通用户和两个管理员账号的一键演示入口，减少原型体验成本。
- 登录身份和会话保存在 LocalStorage。

## 4. 页面结构与交互设计

### 4.1 Agent 对话首页 `/`

**解决的问题：** 统一承接学习资料整理、词库创建、任务创建/修改/删除、学习记录查询和普通问答。

**布局：**

- 顶栏：会话标题、当前工作流状态、新对话/清空当前会话入口。
- 内容区：最大宽度约 820px 的居中消息流。
- 首屏：简洁欢迎语 + 三个高频场景建议（创建学习任务、导入 Excel 词库、查看学习记录）。
- 输入区：固定在内容区底部，包含附件按钮、多行输入、发送按钮和快捷键提示。
- 右侧不常驻面板；执行详情和执行结果内嵌在消息流中，保持阅读专注。

**消息类型：**

- 用户文本消息。
- Agent Markdown 消息，支持列表、表格和代码。
- 文件上传消息，显示文件类型、大小和解析状态。
- 操作预览卡片，展示操作名、目标、配置、影响、确认/取消按钮。
- 高风险删除预览，使用低饱和危险色边框和二次确认。
- Tool 执行轨迹，默认折叠，可查看状态、耗时、脱敏后的参数和结果。
- 进度消息。
- 错误消息，包含可重试或修改输入的引导。

**Agent 操作预览要求：**

- 创建任务：显示任务名称、类型、模式、词库、数量/分组、完整配置和“确认前不会写入”的说明。
- 修改任务：以“修改前 / 修改后”双列对比渲染，而非文本拼接。
- 删除任务：第一次预览说明对象和影响；用户第一次确认后，展示第二次高风险确认卡片，才允许最终删除。
- 创建/导入词库：展示字段映射、样例词条、去重策略和保存目标。
- action_id 在前端记录；重复点击确认时按幂等结果处理。

**Agent 场景路由：**

- 包含“创建/新建”与“任务”时进入任务创建预览；必要信息不足时先追问。
- 包含“修改/调整”与“任务”时进入任务修改预览。
- 包含“删除”与“任务”时进入两阶段删除。
- 包含“学习记录/正确率/错题”时返回结构化统计摘要和页面跳转按钮。
- 上传 `.xlsx`/`.csv` 文件时进入词库导入解析、字段映射和确认流程。
- 其他内容返回可展示 Markdown 的普通问答。
- 首次进入提供快捷场景，点击后自动生成完整示例需求，保证用户能快速体验。

### 4.2 学习任务 `/tasks`

**解决的问题：** 从任务维度查看学习安排，快速继续或进入详情。

**主要区域：**

- 页面标题、页面创建任务入口和通过 Agent 创建任务入口。
- 筛选：全部、进行中、已完成；类型筛选（全部/词汇/听写）。
- 任务列表：名称、类型、状态、进度、创建时间、最近学习时间。
- 移动端改为纵向卡片，避免宽表格不可读。

**交互：**

- 点击任务进入详情。
- 进行中任务提供“继续学习”主操作。
- 空状态提供返回 Agent 的快捷入口。

### 4.3 页面创建任务 `/tasks/new`

**解决的问题：** 不经过 Agent，直接通过表单完整配置任务。

**主要区域：**

- 任务名称、学习类型、固定/长期模式。
- 内容来源：个人词库或已发布公共词库。
- 学习数量、每组数量、强制重做。
- 内容快照预览和任务摘要。

**交互：**

- 所有参数在页面中一次配置。
- 管理员创建的任务只归属当前管理员账户，不提供“替其他用户创建”的选项。
- 保存时由 Task Service 生成内容快照和统一任务配置。

### 4.4 任务详情 `/tasks/:taskId`

**解决的问题：** 查看任务配置、内容快照和学习进度，并完成任务级管理。

**主要区域：**

- 任务概览：名称、类型、模式、状态、进度。
- 学习配置：词库快照、练习数量/分组、创建时间。
- 最近练习记录与错误概况。
- 操作区：继续学习、编辑、删除。

**交互：**

- 固定任务已创建后，学习内容字段只读；如用户尝试修改，提示需删除并重新创建。
- 编辑通过侧边/弹窗表单完成，并展示变更摘要后保存。
- 删除必须二次确认，并明确“练习记录会一并删除”。

### 4.5 词库列表 `/vocabulary`

**解决的问题：** 管理个人词库，同时发现公共词库。

**主要区域：**

- Tab：我的词库 / 公共词库。
- 搜索和“新建/导入”入口。
- 个人词库卡片：名称、词条数、分类、更新时间、来源标记。
- 公共词库卡片：发布者、词条数、分类、复制按钮。

**交互：**

- 新建词库进入独立创建页；支持配置名称、描述、分类、自定义标签和词条。
- 创建页支持 Excel / CSV 上传、真实解析预览和 Excel 模板下载。
- 公共词库复制后立即生成独立个人副本，并提示后续更新互不影响。
- Agent 导入词库后在此处自动出现。

### 4.6 词库详情 `/vocabulary/:libraryId`

**解决的问题：** 查看、搜索和批量维护词条。

**主要区域：**

- 返回入口、词库名称、描述、分类/标签。
- 搜索框、全选、批量删除、添加词条。
- 词条表格或移动端卡片。
- 编辑词条弹窗，支持多个词义。
- 编辑词库信息弹窗，可修改名称、描述、分类和自定义标签。

**交互：**

- 批量选择后显示批量操作条。
- 删除词条要求确认。
- 普通用户查看公共词库时为只读并提供复制入口；管理员可从后台或详情页编辑公共词库。
- 词条词形在同一词库内做重复校验。

### 4.7 词汇练习 `/practice/vocabulary/:taskId`

**解决的问题：** 聚焦完成词汇题，不在聊天上下文中分散注意力。

**布局：**

- 极简练习顶栏：退出/保存并退出、任务名、当前进度。
- 居中题目卡片：单词、音标、题目和选项。
- 底部提交按钮；答题后显示明确的正误反馈和正确答案。
- 完成后展示结果页：正确数、正确率、用时、错题列表和返回任务入口。

**交互：**

- 每次作答即时写入 LocalStorage。
- 页面刷新或重新进入时恢复未完成 Attempt。
- 反馈阶段不可重复提交同题。
- 完成或退出时更新任务进度；重复练习不重复增加首次完成进度。
- 练习中断只保存进度，不出现“暂停任务”状态。

### 4.8 听写练习 `/practice/dictation/:taskId`

**解决的问题：** 提供独立于词汇选择题的听写体验。

**布局：**

- 与词汇练习共享进度和结果框架。
- 核心区域显示音频播放按钮、波形式静态提示（不使用装饰性动画主导界面）、重播按钮和答案输入框。
- 使用浏览器 `speechSynthesis` 播放模拟英文发音。
- 提交后显示拼写正误和正确单词。

**交互：**

- 至少播放一次后可提交，但允许直接作答。
- 支持重播和键盘 Enter 提交。
- 中断后可恢复当前题目和已答记录。

### 4.9 学习记录 `/learning`

**解决的问题：** 用一页轻量概览回答“练了多少、效果如何、哪些需要复习”。

**主要区域：**

- 四个指标卡：练习次数、平均正确率、已掌握词数、待复习错题。
- 最近 7 天练习趋势（使用轻量柱状/折线视觉，不做复杂分析系统）。
- 词汇与听写分项统计。
- 最近练习记录列表。
- 错题列表：单词、错误答案、正确答案、所属任务、最近作答时间。

**交互：**

- 支持按类型筛选。
- 错题可从所属任务继续练习；本阶段不做独立错题练习创建器。
- 管理员从后台查看用户学习概况时复用同一套只读统计组件。

### 4.10 管理后台 `/admin`

**解决的问题：** 公共资源与账户管理。

**布局：**

- Tab：用户管理 / 公共词库 / 操作日志。
- 内容区比学习页面更宽，表格在移动端横向滚动。
- 继续采用黑白灰体系，仅用低饱和语义色标记状态。

**用户管理：**

- 展示昵称、角色、状态、练习次数、最近活跃时间。
- 提供“查看学习概况”和“重置密码”模拟操作。
- 不提供修改答题结果、掌握状态或任务内容的入口。

**公共词库：**

- 展示草稿/已发布状态、词条数、更新时间。
- 管理员可创建、编辑词条、发布/撤回。
- 普通用户仅能浏览已发布词库并复制。

**操作日志：**

- 展示时间、操作人、操作、目标对象和结果。
- 前端模拟日志，覆盖登录、任务、词库和发布操作。

### 4.11 登录 `/login`

**解决的问题：** 表达用户身份与数据隔离，同时提供低摩擦原型入口。

**布局：**

- 左侧品牌与产品定位，右侧简洁登录表单。
- 移动端隐藏品牌说明区，保留表单。
- 提供普通用户、Admin 管理员和 Manager 管理员快捷入口。
- 底部开发工具可重置 Mock 数据。

## 5. Agent 与业务页面协作

```text
用户自然语言
    │
    ▼
Mock Agent（意图识别 / 参数提取 / 预览）
    │  confirmation_required
    ▼
结构化确认卡片
    │  用户确认 action_id
    ▼
统一 Mock Service
    ├── Task Service
    ├── Vocabulary Service
    └── Learning Service
    │
    ▼
LocalStorage 持久化
    │
    ├── 对话消息更新
    ├── 任务列表刷新
    ├── 词库列表刷新
    └── 学习记录刷新
```

页面不直接修改领域数据的原始 LocalStorage 记录，而是调用 `mockApi` 中的 Task、Vocabulary、Practice 等接口。Mock Agent 也只通过这些 API 执行写操作。后续接入 FastAPI 时，优先替换 API 实现，页面组件和 Agent 事件结构保持稳定。

## 6. Mock Agent 事件协议

前端定义与目标 SSE 协议同构的事件结构：

```ts
type AgentEvent =
  | { type: 'message'; data: { content: string } }
  | { type: 'progress'; data: { stage: string; message: string } }
  | { type: 'tool_status'; data: ToolExecution }
  | { type: 'confirmation_required'; data: PendingAction }
  | { type: 'error'; data: { code: string; message: string } }
  | { type: 'done'; data: { executionId: string } };
```

Mock Agent 按短间隔依次发出事件，使聊天界面能真实呈现“思考/执行/等待确认/完成”的过程。界面不依赖真实延迟判断状态，所有状态由事件驱动。

确认动作同样走统一事件流，确认前禁止调用写 API；Service 根据 action_id 检查是否已执行，模拟幂等。

## 7. 视觉系统

### 7.1 风格

- ChatGPT 式单列对话阅读体验。
- Linear 式精细边框、间距和信息层级。
- 中性色为主，不使用蓝紫品牌色或大面积彩色卡片。
- 默认无阴影，弹窗和浮层允许轻微阴影。
- 圆角幅度克制：控件 8px、卡片 12px、弹窗 14px。
- Lucide 线性图标，不使用 Emoji 代替功能图标。

### 7.2 Design Tokens

| Token | 值 |
|---|---|
| `--color-bg` | `#FFFFFF` |
| `--color-bg-subtle` | `#F7F7F8` |
| `--color-sidebar` | `#F9F9F9` |
| `--color-text` | `#171717` |
| `--color-text-secondary` | `#6B6B6B` |
| `--color-text-tertiary` | `#999999` |
| `--color-border` | `#E5E5E5` |
| `--color-hover` | `#EEEEEE` |
| `--color-primary` | `#171717` |
| `--color-success` | `#3F7250` / 浅底 `#EEF6F0` |
| `--color-danger` | `#9D4A45` / 浅底 `#FBF0EF` |
| `--color-warning` | `#8B6330` / 浅底 `#FCF6EC` |
| `--color-info` | `#466B8A` / 浅底 `#EFF5F9` |
| `--font-sans` | 系统字体栈，兼顾中英文 |
| `--radius-sm/md/lg` | `8px / 12px / 14px` |

| `--chat-width` | `820px` |
| `--shadow-popover` | 轻量中性阴影 |

字号采用 12/13/14/16/20/28px 的有限层级；页面标题以 24-28px 为主，不用超大标题制造层级。

### 7.3 响应式

- `>= 1024px`：固定左侧导航，业务内容自适应。
- `768px - 1023px`：导航仍固定，内容左右留白收紧，任务/词库表格允许横向滚动。
- `< 768px`：侧边栏变为抽屉；顶栏显示菜单和当前页面；对话输入区贴底；练习题目保持单列居中；弹窗宽度不超过视口；表格在小屏切换为卡片或可横向滚动。

## 8. 前端代码组织

```text
frontend/src/
├── api/                 # Mock API、LocalStorage、Agent 事件流
├── components/          # 公共 UI、对话消息、业务卡片
├── data/                # 集中管理的 Mock 初始数据
├── features/
│   ├── conversation/
│   ├── task/
│   ├── vocabulary/
│   ├── practice/
│   ├── learning/
│   └── admin/
├── layouts/             # 应用主框架
├── pages/               # 路由页面入口
├── stores/              # 应用状态与数据刷新
```

业务规则（任务删除连带练习、任务确认、公共词库复制、练习进度计算）集中在 Mock Service 层，不散落在 React 组件中。

## 9. 数据持久化与重置

LocalStorage 分区保存：

- `fla.auth`：当前用户身份与登录状态。
- `fla.users`：演示用户。
- `fla.conversations`：会话与结构化消息。
- `fla.tasks`：任务与内容快照。
- `fla.vocabularies`：个人/公共词库。
- `fla.practices`：练习 Attempt、答题记录与错题事实。
- `fla.operationLogs`：关键写操作日志。

首次使用加载集中定义的 Mock 数据。账户菜单和登录页均提供“重置演示数据”，重置后重新载入初始状态并回到 Agent 首页。

## 10. 核心验收流程

1. **Agent 创建任务：** 输入需求 → 信息校验 → 预览 → 取消不写入 / 确认才写入 → 任务列表出现。
2. **页面创建任务：** 配置类型/模式/词库/数量/分组 → 保存 → 任务列表出现。
3. **Agent 修改任务：** 识别任务 → 展示前后差异 → 确认 → 任务配置更新。
4. **Agent 删除任务：** 对象和影响预览 → 第一次确认 → 高风险二次确认 → 删除任务及练习记录。
5. **页面创建词库：** 配置元信息/标签 → 上传 Excel/CSV 或手动添加词条 → 预览 → 保存。
6. **Excel 模板：** 下载模板 → 填写词条 → 回传解析 → 字段校验 → 创建词库。
7. **词汇练习：** 开始 → 作答反馈 → 下一题 → 中途退出 → 恢复 → 完成 → 记录和任务进度更新。
8. **听写练习：** 播放模拟音频 → 输入/提交 → 反馈 → 完成 → 记录更新。
9. **公共词库：** 管理员发布 → 普通用户浏览 → 复制 → 修改个人副本不影响公共源。
10. **响应式：** 桌面与移动端均能打开导航、阅读对话、确认操作和完成练习。

## 11. 原型阶段边界

- 不开发正式后端、数据库、真实 LLM、LangGraph 或 SSE 服务。
- 不实现账号密码加密、真实鉴权或真实语音服务；页面词库创建使用真实 Excel/CSV 解析，Agent 文件流程仍为模拟解析。
- 不实现文档中尚未确定的连续正确次数、自动复习间隔算法和完整错题复习调度。
- 不提供管理员代用户改任务、答题结果或掌握状态的能力。
- 后端的 API Schema、权限校验、幂等和审计能力在本原型中仅以接口和交互契约表达。
