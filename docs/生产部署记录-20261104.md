## 1. 手机软键盘弹起时练习页让位

**上线提交：** `c328d89`  
**当前 release：** `/opt/project2/releases/familylearning-c328d89`  
**回滚目标：** `familylearning-33e0ade`（11-03 11:02 版）  
**数据库：** 无迁移（纯前端改动）

### 问题

手机浏览器里点开听写输入框后，输入法会占掉屏幕下方近一半高度，而练习页仍按 `100vh` 排版：页面底部被键盘盖住，`提交拼写` / `下一题` 按钮点不到，答题时得先收起键盘再操作。

「线上听写」和「错题复习」是同一个组件（`/practice/dictation/:taskId` 与 `.../wrong` 都渲染 `DictationPracticePage`），外壳由 `PracticeLayout` 提供，所以改在布局层一次覆盖两个页面。

### 实现

- 新增 `frontend/src/features/practice/useKeyboardViewport.ts`：监听 `window.visualViewport` 的 `resize` / `scroll`，用「见过的最高的视觉视口」当基准，`基准 - 当前高度 > 120px` 判定键盘弹起；横竖屏用「宽度变化 > 5px」重置基准。iOS 只缩视觉视口、安卓会缩布局视口，两种行为都能覆盖。
- `PracticeLayout` 在键盘态给外壳加 `.is-keyboard`，并写入 `--practice-vh`（视觉视口高度）与 `--practice-vt`（`offsetTop`，iOS 键盘弹起会把页面往上推）。外壳改 `position: fixed`，高度取可视区高度，`practice-main` 成为唯一滚动容器。
- 紧凑化：隐掉长说明文字（保留状态徽标）、底部原型说明、输入框 label、「按 Enter 也可以提交」、自动播放倒计时、音频区说明、朗读内容标签；播放键 64→38px，输入框 28→22px（≥16px 防止 iOS 自动放大），分组条改为单行 flex。
- 按钮固定：`.practice-card-footer` 改 `position: sticky; bottom: 0`，内容再长也钉在键盘上沿。
- 出反馈后播放区、提示卡、输入框都是重复信息，用 `:has(.answer-feedback)` 隐掉，只留「正确答案 + 你的答案 + 朗读 + 下一题」，小屏也放得下。
- 移动端全局提示条由底部改到顶部（`top: calc(var(--mobile-topbar-height) + 8px)`），否则正好压住提交按钮。
- `index.html` viewport 增加 `interactive-widget=resizes-content`（Chrome Android 直接缩布局视口）与 `viewport-fit=cover`（`env(safe-area-inset-bottom)` 生效前提）。

### 验收
