## 3. 已覆盖的关键场景

- 注册、登录、刷新、登出、停用账户、跨用户资源隔离。
- 管理员的两个管理员账户、用户列表、重置密码、只读学习统计。
- 词库复制、公共词库发布/撤回、标签和词条编辑。
- CSV/XLSX 导入、模板、预览编辑、版本冲突、确认导入和重复确认。
- 任务快照不可变、固定任务锁定、长期任务配置持久化。
- Attempt 中断恢复、重复提交拒绝、线上判分、线下自查来源。
- 固定任务覆盖进度、长期任务掌握进度、统计事实重算、删除级联。
- Agent LLM 超时/429/5xx、Prompt 变量校验、Tool 权限过滤。
- Agent 创建/修改任务、两阶段删除、词库创建/导入。
- `action_id + draft_version + config_hash` 校验、重复确认和跨用户拒绝。
- SSE 顺序、事件重放、执行详情和敏感字段脱敏。
- Checkpointer 跨进程重启恢复。

## 4. MySQL PoC 结论

MySQL 8.4.7 实测通过。Checkpoint 数据库必须使用 `utf8mb4_0900_ai_ci`（或同系列 0900 排序规则），否则 Saver 的 JSON_TABLE 查询会发生排序规则冲突。详细记录见 `技术决策记录.md`。
