# 家庭学习助手开发总结

**版本：** 1.0  
**完成日期：** 2026-11-02  
**状态：** Phase 0–9 代码、自动化测试、MySQL PoC 和部署文档已完成；Docker 容器构建与外部 LangSmith 验证受本机条件限制，已明确标注。

---

## 1. 完成的功能

- JWT Access Token + 可撤销、轮换 Refresh Session。
- 个人/公共词库、学科、自定义标签和词条完整编辑。
- 公共词库复制、发布、撤回和删除。
- `.xlsx/.csv` 服务端上传、模板下载、预览、逐条编辑、版本冲突和确认导入。
- 列名兼容：规则优先匹配中英文表头；无法识别时将表头和最多 5 行样例交给 LLM 生成结构化映射，再校验索引、重复列和必填字段。
- 字段自动补充：英文缺失音标/中文释义、中文词语缺失拼音时批量调用模型；仅填补空字段，失败项在预览中标记，确认前仍可手动修正。
- 听写任务创建、快照、修改、删除；固定任务与长期任务规则分离。
- 线上自动判分、线上下载自查、自动/手动播放配置、朗读次数和提示内容。
- Attempt 中断恢复、任务进度、学习统计、错题和管理员只读统计。
- LangGraph Agent：任务创建/修改/两阶段删除、词库创建/导入、学习查询。
- `action_id + draft_version + config_hash` 确认协议与重复确认保护。
- SSE 持久化事件、游标重放、客户端断开后后台继续执行、服务重启恢复。
- Prompt 文件版本/哈希、LLM 重试/超时/429/5xx 映射、Token 使用量。
- Tool Registry 权限过滤、执行详情和敏感字段脱敏。
- React 前端真实 HTTP/SSE 接入，桌面与移动端流程。
- 两个开发管理员和两个生产 Bootstrap 管理员配置能力。
- Docker/Compose、Nginx、健康检查、指标、备份恢复和历史清理文档/脚本。

## 2. 架构实现

```text
React/TypeScript
      │ HTTP + SSE
      ▼
FastAPI Routers
      │
      ▼
Module Services ──────── LangGraph AgentRuntime
      │                         │
      ▼                         ▼
Module Repositories       Tool Registry / LLM Adapter
      │                         │
      ▼                         ▼
SQLAlchemy Business DB     MySQL Checkpoint DB
```

- 前后端分离。
- Service 是业务规则和事务入口。
- Repository 仅由所属模块 Service 调用；管理员/导入流程已做边界修正。
- Agent 不直接访问业务数据库；写入通过 Task/Vocabulary/Content Service。
- Conversation 消息与 LangGraph Checkpoint 分库/分表保存。
- Prompt 位于 `backend/app/modules/agent/prompts/`，执行时记录版本和内容哈希。

## 5. Agent Graph 与 Tool

主图节点：

1. `classify`：LLM/Intent 分类并程序校验白名单。
2. `prepare`：调用业务 Service 生成结构化确认草稿。
3. `wait`：LangGraph Interrupt，校验 action/version/hash；删除任务进入第二阶段。
4. `respond`：普通对话或学习统计。
5. 后台执行线程：独立于 SSE 连接执行 Graph，事件持久化。
6. `stream_run`：从 `agent_run_events` 轮询/重放，不重复执行 Graph。

Tool Registry：

- `learning.stats`
- `task.create_preview`
- `task.update_preview`
- `task.delete_preview`
- `vocabulary.create_preview`
- `vocabulary.import_preview`
- `admin.execution_detail`（仅管理员）

## 7. 已知问题与未完成事项

1. **Docker 镜像未实际构建**：本机无 Docker daemon；Dockerfile/Compose 已提供，生产直接启动方式已实际验证。
2. **LangSmith 未验证**：无外部 API Key；标准环境变量可启用，核心功能不依赖。
3. **真实外部 LLM 未联调**：Adapter 的重试、超时、429/5xx 和结构化响应已用 MockTransport 测试；默认使用 Mock Provider。
4. MySQL Checkpoint 数据库必须使用 `utf8mb4_0900_*` 排序规则。
5. 浏览器语音依赖客户端 Web Speech 和系统语音包。
6. 当前 Agent 后台执行在单进程线程池模型中串行化 Graph 写入；多实例水平扩展前应引入共享任务队列或专用 Agent Worker。

## 8. 部署入口

详见 `docs/部署说明.md`。推荐生产启动：

```bash
uv run alembic upgrade head
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```

前端使用 `VITE_API_BASE_URL=/api/v1` 构建，由 Nginx 反向代理 SSE 和 API。
