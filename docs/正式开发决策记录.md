## 2. 原型优先规则

以下已验收原型行为为正式产品基线：

1. 词库移除分类字段，只保留学科和自定义标签。
2. 固定任务和长期任务都不单独填写学习数量；任务数量等于用户勾选词条数量。
3. 固定任务无分组；长期任务可配置每组数量。
4. 用户可通过勾选或 `2-10`、`4,8` 等序号表达式选择词条，二者同步。
5. 页面和 Agent 均可创建任务，均可使用个人词库或已发布公共词库。
6.  Agent 确认卡可编辑任务或词库的全部页面可编辑字段，编辑后仍需确认。
7. 听写是默认任务类型，支持线上/线下、自动/手动、播放间隔、朗读次数和朗读内容。
8. 词库导入支持 Excel/CSV 模板、预览、逐条编辑、增删词条和确认保存。
9. 对话区固定显示“创建学习任务 / 导入 Excel 词库 / 查看学习任务”三个快捷入口。
10. 练习与对话分离，学习进度保存在独立业务数据中。

## 3. 对正式实施的影响

### 3.1 Task / Practice

- V1 TaskType 正式只接受 `dictation`。
- 原型中的词汇练习页面保留为历史原型资产，不纳入 V1 正式任务入口。
- Vocabulary / Question 模块仍保留，用于词库、听写内容和未来扩展。
- 固定任务进度按覆盖的唯一词条数计算。
- 长期任务进度按掌握词条数计算，掌握阈值采用配置化默认值。

### 3.2 线下听写

- 用户自查正确/错误可作为正式 Practice Answer。
- `evaluation_source=self_report` 必须保存，统计仍需可追溯来源。
- 自查结果进入正确率、掌握状态和复习计划。

### 3.3 听写播放

- 听写配置至少包含：
  - `dictation_mode`: `online/offline`
  - `playback_mode`: `auto/manual`
  - `interval_seconds`
  - `repeat_count`
  - `reading_content`: `phonetic/meaning`
- 音频朗读内容和页面显示内容一致；英语为音标或中文，语文为拼音或中文。
- 浏览器 Web Speech 可作为原型与早期实现的后端下发替代方案，但正式接口应只依赖配置数据。

### 3.4 确认编辑

- Pending Action 保留稳定 `action_id` 和递增 `draft_version`。
- 每次编辑通过后端重新校验并递增版本。
- 确认请求必须携带当前 `draft_version` 与 `config_hash`。
- 确认旧版本必须失败，不能执行已过期配置。
- 重复确认同一版本仍由 action_id 幂等保护。

### 3.5 Public Vocabulary

- 公共词库复制直接生成独立词条数据。
- 不建设公共词库版本历史。
- Task Snapshot 仍独立保存完整内容，不能依赖复制后的词库继续变化。

### 3.6 Agent 运行

- 使用 `agent_run_events` 持久化可回放事件。
- SSE 重连使用 `event_id/sequence` 游标。
- 同 Conversation 使用数据库租约锁。
- 管理员可查看完整执行详情；凭证、Token、Cookie、密码等仍需脱敏。
- Prompt 内容可向管理员受控展示，但 Prompt 管理编辑后台仍不属于 MVP。

## 4. 仍需 PoC、但不改变产品决策的事项

1. LangGraph 官方/可维护 MySQL Checkpointer 的可用版本和实现方式。
2. SSE 同步执行在 FastAPI + 客户端断开时的进程行为。
3. `agent_run_events` 的保留周期和清理策略。
4. 服务端 XLSX/CSV 解析器选型与资源限制。
5. SQLite/MySQL JSON、唯一约束和 UTC 时间兼容。
6. 学科配置表的初始化与缓存策略。
7. 掌握阈值和复习参数的管理配置方式。

这些属于技术实现验证，不作为重新讨论产品方向的前提。
