**上线时间：** 2026-11-20 13:53（Asia/Shanghai）
**代码基线：** `main @ cf5f18f` + `frontend/.env.production` 改为 `VITE_BASE_PATH=/`
**Release：** `/opt/project2/releases/familylearning-c28331c`（原地替换 `frontend/dist`，未切软链）
**回滚目标：** `/opt/project2/app-v2/frontend/dist.bak-20261120-135303`（子路径版产物）
**数据库：** 无迁移（仍为 `0006_practice_attempt_round`）
**前端入口：** `assets/index-DuumH0NT.js`（SHA256 `036aadcf…`）、`assets/index-LcqUY8g0.css`（`e109e045…`，未变）
**证书：** Let's Encrypt `zijixue.xyz`（含 `www`），ECDSA，有效期至 2027-02-18，webroot 方式自动续期

### 背景

`yidongxun.com` 已停止服务，应用在 2026-11-17 临时挂到 `sunxinshan.site/zijixue` 子路径下（前端 base=`/zijixue/`）。本次把正式域名收敛到 `zijixue.xyz`，站点走根路径，前端 base 回到 `/`。

### 实现

**前端（一处改动）**

- `frontend/.env.production`：`VITE_BASE_PATH=/zijixue/` → `/`。
- 无需改代码：`vite.config.ts` 读 `VITE_BASE_PATH` 作为 `base`；`App.tsx` 的 `routerBasename` 与 `httpClient` 的 `API_BASE_URL` 都由 `import.meta.env.BASE_URL` 推导，base 为 `/` 时自动得到 `/api/v1`。
- **按 HEAD 干净构建**（`git worktree`），刻意不带工作区未提交改动：那批改动里的管理页调用了线上后端尚未存在的 `/admin/checkpoints`，混进去会让管理页直接报错。

**Nginx（新增一个站点配置）**

- 新增 `/etc/nginx/conf.d/zijixue.xyz.conf`（源文件 `/opt/project2/nginx/zijixue.xyz.conf`）：
  - 80：仅放行 `/.well-known/acme-challenge/`，其余 301 到 https；
  - 443 `www`：301 到裸域名；
  - 443 裸域：`/api/` → `127.0.0.1:8002`（`proxy_buffering off`，保 SSE 流式），`/` → `127.0.0.1:8003`。
- `sunxinshan.conf` 的 `location ^~ /zijixue/` 改为 `rewrite ^/zijixue/(.*)$ https://zijixue.xyz/$1 permanent`，`= /zijixue` 直接 301 到新域名。旧 URL 全部保留可达。
- 证书独立一张，不与 `sunxinshan.site` 混签：任一域名下线不用重签另一个。

**产物切换**

- 构建产物先上传到 `/opt/project2/releases/.dist-zijixue-new` 暂存，脚本内校验 `index.html` 引用的是 `/assets/` 才允许切换。
- 切换方式：`mv dist dist.bak-<时间戳>` → `mv 暂存目录 dist`。保持 `.../frontend/dist` 这个路径不变，`serve_spa.py` 启动时已 `resolve()` 了该路径，因此**无需重启服务**。
