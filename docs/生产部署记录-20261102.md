## 6. 回滚

代码回滚：

```bash
sudo systemctl stop project2
ln -sfn /opt/project2/releases/453c74f /opt/project2/app-v2
# 恢复备份中的旧 backend.env 与旧 project2.service 后：
sudo project2-apply-service
```

数据库与旧代码不兼容。回滚旧代码前，必须同时恢复迁移前数据库备份；不要在旧代码上直接使用当前新 schema。

推荐恢复顺序：

1. 停止 `project2`。
2. 先备份当前新库。
3. 由具备 MySQL 管理员权限的人员恢复迁移前备份。
4. 恢复旧环境文件和旧 systemd 单元。
5. 切回旧 release 并仅通过 systemd 启动。
6. 验证公网健康状态。

在新服务验收稳定前，不得删除：

- `/opt/project2/releases/453c74f`
- `/opt/project2/releases/familylearning-198c125`
- `/opt/project2/shared/storage`
- `/opt/project2/backups/`
- 任何 `legacy_*` 表
