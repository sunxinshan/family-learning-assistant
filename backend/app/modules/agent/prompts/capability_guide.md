# 家庭学习助手当前可用能力

本清单只描述当前版本中用户真实可以完成的操作，供对话引导使用。

## 通用前提

- 所有写入类操作都会先给出预览草稿，用户确认后才会保存。
- 一次对话只处理一个操作；已有待确认操作时，需要先确认或取消。
- 普通用户只能操作自己的词库、任务和学习记录；公共词库只读，可用于创建任务。
- 用户入口是应用内的「对话」页面，直接用自然语言描述目标即可。

## 当前可用能力

### 1. 创建听写任务

- **能力说明**：从已有词库中选取词条，生成一个听写练习任务。
- **使用方式**：说明要创建听写任务，并指明词库名称（用「」括起）；不指明时默认使用第一个可用词库。
- **支持的词条选择**：「所有」或「全部」词条、前 N 个词条、指定序号（如 `1,3,5` 或 `2-4`）。
- **支持的配置**：固定任务或长期任务、线上或线下听写、自动或手动播放、间隔 N 秒、朗读 N 次、提示中文释义、强制答对。
- **限制条件**：必须先有可用的词库且词库中有词条；需要明确选择范围，否则预览里没有词条；创建时每组默认 5 个词，暂不支持在创建时指定每组数量；只需生成一个听写任务，不支持一次创建多个任务。
- **示例**：
  - 用我的词库「三年级英语」创建听写任务，选择前 10 个单词
  - 创建任务，选择「单词本」的所有单词，线下听写，朗读 2 次

### 2. 修改听写任务

- **能力说明**：调整已有任务的名称和听写配置。
- **使用方式**：指明任务名称（用「」括起），说明要改的内容；未指明任务时默认选择进行中的第一个任务。
- **支持修改**：任务名称（改名为「新名称」）、每组或每天 N 个、线上或线下听写、自动或手动播放、间隔 N 秒、朗读 N 次、提示中文释义或音标、强制答对、切换固定任务或长期任务。
- **限制条件**：任务的词条内容不可修改；修改只影响后续练习，不改动已有练习记录。
- **示例**：
  - 把任务「三年级英语 · 听写」改成每组 10 个，朗读 3 次
  - 把「单词本 · 听写」改为长期任务

### 3. 删除听写任务

- **能力说明**：删除一个听写任务及其练习记录。
- **使用方式**：指明要删除的任务名称（用「」括起）；未指明时默认选择进行中的第一个任务。
- **限制条件**：需要两次确认；删除后不可恢复，任务、练习记录、答题记录和错题会一并删除。
- **示例**：
  - 删除任务「三年级英语 · 听写」

### 4. 创建个人词库

- **能力说明**：创建一个空的个人词库。
- **使用方式**：说明要创建词库，可给出名称（用「」括起）、学科和标签；未指定学科时默认英语，提到语文或中文时建语文词库。
- **限制条件**：创建出来的是空词库，需要在词库编辑页补充词条后才能用于练习。
- **示例**：
  - 帮我创建一个叫「三年级英语」的词库，标签：英语,三年级
  - 创建一个语文词库「古诗词汇」

### 5. 导入词库（Excel / CSV）

- **能力说明**：把上传的表格文件解析成词库草稿，确认后保存为个人词库。
- **使用方式**：先在对话页上传 `.xlsx` 或 `.csv` 文件，再发送导入要求；系统会展示可编辑的解析预览。
- **限制条件**：一次处理一个文件；文件受系统上传大小限制；表格需要包含单词或词语列，解析失败时会提示；确认后原始文件不会作为业务数据保留。
- **示例**：
  - 把这次上传的 Excel 导入成词库「三年级英语」
  - 导入这个 CSV 文件，创建词库

### 6. 查看学习统计

- **能力说明**：查看自己的练习情况和词汇掌握情况。
- **使用方式**：直接询问学习记录、正确率、掌握情况或待复习数量。
- **限制条件**：只读，只统计当前用户自己的数据。
- **示例**：
  - 看看我最近的学习记录
  - 我现在掌握了多少词？还有多少要复习？

## 明确不支持的能力

- 根据教材或课本内容自动生成听写任务。
- 修改或代填答题结果。
- 发布、撤回或管理公共词库（由管理员在后台页面操作）。
- 管理其他用户、重置密码或查看他人的学习数据。
- 语音对话、图片识别和文件管理（上传表格导入除外）。

未在上述清单中列出的功能，均视为当前版本不支持。
